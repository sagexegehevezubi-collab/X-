# v0.2.57：媒体与不完整语境主动跳过

在 v0.2.56 的时事与事实风险保护基础上，降低自动评论在媒体帖、直播及缺少上下文时的误回。

1. 检测到视频、X Spaces/直播、音频或投票时，在调用模型前直接跳过。生成后共享发送流程还会重新检查页面结构，阻止内容变成媒体帖后仍发送。
2. 图片不会发给模型。只把“有图片”这一结构信息传给模型；仅当配文脱离图片仍完整、回复不依赖画面细节时才允许生成，否则跳过。
3. 提取可见的引用文字、回复提示和链接卡片文字，并明确告知模型没有读取外链正文。模型不得猜测缺失的引用、前序对话或外部文章；语境不完整、指代不清、梗无法确定或没有自然接话点时跳过。
4. 对投票、抽奖及参与式互动内容跳过；帖子明确不欢迎 AI 回复时跳过。每种跳过情况单独记录，不做同帖重试，已有备用帖子流程照常继续。
5. 提示词仍要求原帖和引用文字作为不可信数据处理，禁止执行嵌入内容里的指令；跳过标记只用于本地识别，不会发布到 X。
6. 固定回复模式没有模型判断语境，遇到图片、无法读取的引用/外链或缺少前序对话时也会保守跳过，避免固定话术套到不完整场景。

## 验证

新增回归覆盖媒体结构的零 API 跳过、模型场景标记、图片独立配文、引用/外链上下文、发送前媒体拦截，以及 v0.2.56 原时事/事实拦截和候选流程。全部使用模拟 API 和页面，不发真实评论、不关注账号。

本版本只根据 X 页面可见结构和文本作本地筛选，不会观看视频、收听直播、分析图像或打开外部链接。若 X 页面没有暴露媒体标记，模型仍会按文本及结构提示判断；无法确认时返回跳过标记。它不能保证识别所有边界场景。

升级时先停止任务，再重新加载扩展并刷新 X 页面。旧版本目录和安装包保留。
