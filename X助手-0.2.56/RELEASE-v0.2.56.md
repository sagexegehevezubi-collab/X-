# v0.2.56：避开时事与未经核实的事实

针对模型拿旧知识纠正新事件、将当前日期误判成未来的问题，增加以下四项保护。

1. 生成前用本地规则筛选新闻、人物任免、公司上市/融资/收购、财报股价、产品发布等时效内容。明确命中时不调用 API；名字本身不决定跳过。模型通过专用内部跳过标记补充语义筛选，后台统一转换成 `[SKIP]`。
2. 系统提示词明确没有联网核验能力，不凭训练记忆纠正日期、身份或上市状态，不确认原帖传闻，不新增未经提供的价格、日期或产品参数。User 消息附浏览器本地当前日期和时区，日期不充当新闻核实依据。
3. 生成结果、共享发送函数及后台发送预占执行事实风险检查；打开回复框前、编辑器就绪后、点击发送前再次检查。风险结果不发送，也不通过删字或改万能话术绕过。
4. 时事/事实风险不触发同帖重写或普通网络错误重试。榜单回到既有候选选择流程，指定博主继续已有备用帖，列表关注沿用最多两帖和原20秒换帖节奏；没有备用则继续下一位，已完成的关注保留。质量日志、状态及失败记录显示具体跳过原因，不计入成功评论。

- v0.2.55 完整目录、ZIP、Git 标签及旧提示词保持原样；新版提示词快照见 `PROMPT-v0.2.56.txt`，实际生成逻辑在 `background.js`。
