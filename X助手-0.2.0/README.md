# X助手（Chrome MV3）

## 安装
1. 在 Chrome 打开 `chrome://extensions` 并开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本目录。
3. 点击工具栏中的扩展图标，再点“打开网页版控制台”。控制台选择任务，通过“设置模型 API”。
4. 重新加载扩展并刷新 X 页面。

## 模型接口

设置页支持 OpenAI Chat Completions 兼容接口，可直接选择 DeepSeek、豆包（火山方舟）、OpenRouter 或自定义服务。选择豆包时，API 地址使用火山方舟地址，模型名称填写控制台创建的 Endpoint ID（例如 `ep-xxxx`）。自定义服务需要填写完整的 HTTPS 接口地址、模型名称和对应的 API Key；兼容本机网关时可使用 `http://localhost`。

中转站如果返回 `unknown field "messages"`，扩展会自动把请求转换为 OpenAI Responses 格式并重试 `/v1/responses`，无需手动改接口地址。

扩展也兼容多种网关嵌套返回格式；如果服务确实返回空内容，控制台会提示“接口已响应，但没有识别到文本字段”。

请求会明确使用非流式模式；即使网关仍返回 SSE，也会自动合并文本增量。

功能二会按帖子 ID 重新定位被 X 虚拟列表替换的节点，继续识别下滑后加载的关键词帖子。

如果回复框或发送控件卡住，功能二会在 20 秒后自动刷新 X 并恢复当前任务；模型或其他错误仍使用较长的恢复等待，避免重复请求。

功能二只处理发布时间在最近 4 小时内的符合关键词帖子；每成功回复 10 条后自动刷新 X，并继续任务。

功能二每条成功评论至少间隔 20 秒；累计成功评论 100 条后自动休息 10 分钟，再继续评论任务。成功回复 10 条仍会按原规则刷新 X。

榜单博主互动只评论榜单博主，不执行关注；控制台会显示总进度、每个并行工作路的完成数、当前博主和当前动作。

控制台顶部任务状态会显示任务类型和当前动作，例如扫描帖子、等待评论限速、定位回复框、发送确认、刷新后继续等。

所有 AI 生成的评论回复都会取消句首情绪词和“记得回踩喔/记得回访喔”固定结尾，直接输出针对内容的自然回复。固定回复不做修改。

v0.2.20 起，首页互关、榜单博主、回复自己帖子评论和手动草稿使用不同场景提示；AI 输出会经过本地自然度检查，过于工整时最多自动重试一次。抽奖、无文字图片、激烈骂战、严肃悲剧或没有可接内容的帖子会安全跳过，不会把 `[SKIP]` 发成评论。

榜单博主互动控制台还会单独显示当天成功评论的数量，并按帖子去重，避免重复发送事件导致统计多算。

榜单任务遇到单个博主主页、帖子或回复区域无法识别时，最多尝试 3 次；仍失败会记录跳过原因并进入下一位，不会一直停在同一个博主。

指定博主互动支持手动输入账号，逐个处理每位博主最近 4 小时内的原创帖子；第一版每位最多评论 5 条，评论间隔至少 20 秒。任务单独显示进度，并统计当天评论总数和涉及博主数；单个主页或帖子连续失败 3 次会跳过。

v0.2.24 兼容 `www.x.com` 页面；关键词帖的“生成回复草稿”按钮在榜单、指定博主等任务模式下也会继续显示。

v0.2.25 起，榜单同一博主可在一天内多次导入和互动，不再因为之前已完成该博主而排除整位账号。每轮对每位博主最多评论一条已加载的最新未处理帖子；仅跳过已评论或发送结果不确定的同一帖子，旧版记录中的帖子 ID 也继续用于去重。

v0.2.26 起，AI 回复必须包含至少一个文字或数字；纯标点、纯表情和空白内容会重试一次，仍无效则跳过，发送前也会再次拦截。

v0.2.27 起，榜单导入支持跳过前面博主数量。例如跳过 200、导入 200，会自动翻页读取第 201–400 位；跳过按当前筛选后的唯一博主计数。
