# X助手

X助手 Chrome MV3 扩展的版本备份仓库。

## 版本

- `X助手-0.2.0`：初始备份版本，标签 `v0.2.0`
- `v0.2.1`：扩展首页互关/评论关键词，保留原有关键词并加入用户指定词语
- `v0.2.2`：加入按顺序轮换的 AI 回复情绪开头词池，严肃语境自动跳过
- `v0.2.3`：功能二每条评论至少间隔 20 秒，并在总控制台显示当日成功评论数
- `v0.2.4`：兼容拒绝 `max_tokens`、要求 `max_completion_tokens` 的 API 网关
- `v0.2.5`：中转站直接使用 `max_completion_tokens`，并增强字段错误识别
- `v0.2.6`：中转站返回 `unknown field "messages"` 时自动切换到 Responses `/v1/responses` 协议
- `v0.2.7`：兼容嵌套 Responses、Anthropic、Gemini 等多种返回文本格式，避免误报空草稿
- `v0.2.8`：强制关闭流式返回并兼容 SSE 文本增量，修复中转站返回内容无法提取的问题
- `v0.2.9`：按帖子 ID 重新定位 X 虚拟列表节点，修复功能二只识别前几个帖子的情况
- `v0.2.10`：回复框或发送控件卡住时，20 秒后自动刷新 X 并恢复任务
- `v0.2.11`：功能二只回复最近 4 小时内的帖子，每成功回复 10 条自动刷新 X
- `v0.2.12`：所有 AI 回复自动追加“记得回踩喔”，避免重复添加
- `v0.2.13`：功能二成功评论间隔调整为 35 秒
- `v0.2.14`：控制台顶部任务状态显示任务类型、当前动作和上次状态
- `v0.2.15`：功能二评论间隔改为 20 秒，每成功评论 100 条自动休息 10 分钟
- `v0.2.16`：完善榜单博主互动进度，显示总完成数、每路进度、当前博主和当前动作
- `v0.2.17`：榜单博主互动改为只评论，不再强制关注
- `v0.2.18`：功能二 AI 回复取消句首情绪词和固定结尾话术
- `v0.2.19`：所有 AI 评论回复取消句首情绪词和固定结尾话术
- `v0.2.20`：加入场景化回复提示、自然度本地评分、最多一次降级重试和安全跳过机制；AI 回复参数调整为更短、更口语化的模式
- `v0.2.21`：榜单博主互动后台主页增加今日成功评论数量统计
- `v0.2.22`：榜单单个博主识别或加载失败最多重试 3 次，仍失败自动跳过，避免任务卡住
- `v0.2.23`：新增指定博主互动板块，处理近 4 小时原创帖子并单独统计评论总数和涉及博主数
- `v0.2.24`：兼容 `www.x.com` 页面，并让关键词帖的手动回复草稿按钮不受当前自动任务模式影响
- `v0.2.25`：榜单允许同一博主多次导入和互动，仅按帖子去重，并兼容旧版评论记录
- `v0.2.26`：拦截 AI 生成的纯标点、纯表情和空白回复；榜单遇到无效回复会重试后跳过，不再发送异常内容
- `v0.2.27`：榜单导入增加“跳过前面博主数量”，可直接导入后面的榜单区间

以后每次迭代保留一个版本目录，并使用对应的 Git 标签记录，便于回退和恢复。
